# Duolingo vs Babbel – Text Analytics

## Project Overview

This project performs a comparative **Text Analytics analysis of user reviews for Duolingo and Babbel** collected from the Google Play Store.

The objective is to understand what users like and dislike about both language-learning applications and identify differences in user opinions, topics, and sentiment using Natural Language Processing (NLP) techniques.

## Objectives

- Compare user reviews of Duolingo and Babbel
- Identify frequently discussed topics and phrases
- Analyze positive and negative user feedback
- Compare sentiment patterns between the two applications
- Identify important differences in user opinions using text analytics

## Methodology

The project follows these major steps:

1. **Web Scraping** – Collection of Google Play Store reviews
2. **Data Cleaning** – Handling missing values, duplicates, and irrelevant text
3. **Text Preprocessing** – Lowercasing, tokenization, stopword removal, and lemmatization
4. **TF-IDF Analysis** – Identification of important terms
5. **N-Gram Analysis** – Unigram, bigram, trigram, and 4-gram analysis
6. **Word Cloud Analysis** – Visualization of frequently occurring words
7. **Sentiment Analysis** – Rating-based and VADER-based sentiment analysis
8. **Comparative Analysis** – Comparison of Duolingo and Babbel
9. **Theme Analysis** – Identification of common positive and negative themes
10. **Business Insights** – Interpretation of user feedback and potential improvement areas

## Key Analysis

The project compares the two applications based on:

- User ratings
- Frequently used words
- Bigrams, trigrams and 4-grams
- TF-IDF scores
- Positive and negative themes
- Text-based sentiment
- Rating vs sentiment mismatches
